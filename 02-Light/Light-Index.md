# Module 2 — Light

Brief and assignments: [[Syllabus#Module 2 — Light]] · Schedule:
[[Roadmap#Phase 2 — See the light]] · Progress: [[Progress-Tracker]]

**The module in one line:** light has only four properties worth describing — quality,
direction, colour, and contrast ratio. Learn to name them and you can reproduce any
light you've seen.

## Concepts

### Physics you can't avoid
- [[Quality-of-Light]] — hard vs soft, governed by *relative* source size
- [[Inverse-Square-Law]] — double the distance, quarter the light
- [[Contrast-Ratio]] — key-to-fill in stops

### Describing light
- [[Direction-of-Light]] — front, 45°, side, back, rim, top, under
- [[Colour-Temperature-of-Light]] — golden hour, blue hour, shade, mixed sources

### Working with what's there
- [[Natural-Light]] — window, open shade, overcast, harsh midday
- [[Light-Modifiers]] — reflector, diffuser, scrim, flag, bounce
- [[Available-Light-Discipline]] — when *not* to add light

### Adding light
- [[Flash-Fundamentals]] — guide number, TTL vs manual
- [[Sync-Speed]] — and HSS
- [[Bounce-Flash]] — never straight ahead
- [[Off-Camera-Flash]] — one light, one stand
- [[Balancing-Flash-and-Ambient]] — shutter for ambient, aperture/power for flash

## Assignments
A2.1 window study · A2.2 hard-to-soft · A2.3 fall-off · A2.4 four times of day ·
A2.5 backlight rescue · A2.6 one light only

than every other assignment in this module combined. Do it first, do it properly.
